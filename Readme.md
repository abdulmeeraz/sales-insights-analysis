# Data Insights Analysis Project 📊

## Description
An end-to-end data analysis project using Pandas to analyze sales data and generate business insights.

## Steps Covered
- Data loading
- Data exploration
- Feature engineering
- Sales analysis
- Insight generation

## Insights
- Identified total and average sales
- Found best-selling product
- Analyzed category-wise revenue

## Concepts Used
- Pandas DataFrame
- CSV handling
- Aggregation
- GroupBy operations

## How to Run
1. Install Pandas
2. Run:
        python main.py
